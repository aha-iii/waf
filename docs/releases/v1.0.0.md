# Nerve WAF v1.0.0

**发布日期**：2026-11-12  
**仓库**：`nerve/nerve-waf/nerve-defender`  
**配套版本**：Nerve Antibody `v0.1.0`（可选 `expert` feature）

---

首个正式发布版本。除能力基线外，本次重点解决「clone 下来装不上、编译不过」这类会直接阻断评估的问题，
并把安装、验证、故障定位串成一条可复现的链路。

## 本版重点

**1. 一键安装真正可用**

```bash
git clone https://github.com/ahaiii/waf.git nerve-waf
cd nerve-waf/deploy
bash install.sh
```

脚本按 `依赖自检 → 生成 .env → 构建启动 → 健康轮询 → 冒烟验证` 顺序执行，失败时自动打印相关容器日志。
支持 `--dry-run`（只看将执行什么）、`--port` / `--agent-port`（改端口）、`--uninstall` / `--purge`（卸载）、
`--force-env`（重建配置）、`--verbose`、`--version`。退出码分级，便于 CI 与自动化判断失败环节。

> 此前 `scripts/` 与 `deploy/scripts/` 被 `.gitignore` 吞掉，脚本从未入库——这是「按文档执行却找不到文件」的
> 根因。本版已改为白名单并放行。

**2. 修掉两个编译级阻塞**

- `test_snapshot_contract.rs` 中 `fn` 被误写为 `fe`、`WafEdgeSnapshot` 被误写为 `WafEdgeSeapshot`，
  `cargo test` 在解析阶段即失败。
- `vendor/proxy-wasm-test-framework` 示例中的 `"\e"` 是非法转义，rustfmt 1.8.0 起直接报错，导致 `cargo fmt` 无法运行。

**3. 新增 CI 四道门禁**

`.github/workflows/nerve-waf-ci.yml`：`cargo fmt --check`、`cargo clippy -D warnings`、`cargo test`、`helm lint`。
配合本版对 133 个文件的 fmt 归一，此后格式与 lint 不再靠人工维持。

**4. 安装后可以自己验**

`scripts/smoke-test.sh` 从「端口能不能连」改为 6 项端到端检查：Controller 健康、站点存在、策略已绑定、
边缘检测生效、事件落库、Agent 快照同步。自动发现站点 id，支持 `--json`。

**5. 误报与可运维性**

- `sql-003`（SQL 注释）由 `--|#|/\*` 收紧为 `\s--\s|['"]\s*--|/\*`，不再把 URL 锚点 `#`、路径中的裸 `--`
  判为注入。
- Controller 端口被占用时不再输出 panic + backtrace，改为提示换端口参数与查占用命令，并以 `exit(1)` 退出。

## 升级注意（破坏性）

| 项 | 变化 | 影响 |
|---|---|---|
| 风险分类返回值 | `insufficinet_data` → `insufficient_data` | 外部系统若按该字符串判断，需同步修改 |
| `sql-003` 判定范围 | 收紧 | 仅命中 `#` 或裸 `--` 的历史告警不再产生，看板/告警统计会出现台阶式下降 |

## 验证情况

| 项 | 结果 |
|---|---|
| `cargo fmt --all --check` | 通过 |
| `cargo clippy --workspace -- -D warnings` | 通过 |
| `cargo test -p nerve-waf-store -p nerve-waf-controller -p nerve-waf-dataplane` | 27 passed / 0 failed |
| 源码三进程启动 | Controller `/api/health` 返回 `{"ok":true}`；Agent 快照 generation 同步 |
| 边缘检测 | 正常请求转发 200；`/x?q=sqlmap` 返回 403 拦截页并落库事件（`rule_id=custom-uri-sqlmap`） |

| Compose 三套组合 | `docker compose config --quiet` 均通过（基础 / standalone / prebuilt overlay） |
